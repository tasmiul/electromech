## Brand & Style

This design system expresses heavyweight industrial power governed by surgical Swiss precision. Built for an international electromechanical and advanced industrial technology firm, the visual language balances immense mechanical scale with micron-level engineering clarity. 

The aesthetic draws from architectural blueprints, high-performance telemetry consoles, and modern editorial Swiss graphic design:
- **Tension & High Contrast:** Unapologetic structural shifts between deep, pitch-black command surfaces (`#0B0F14`) and stark, sterile engineering white surfaces (`#FFFFFF`).
- **Technical Rigor:** Crisp hair-thin boundary lines, mechanical coordinate systems, subtle crosshair markers (`+`), and technical datum labels reinforce an environment of zero-tolerance quality control.
- **Architectural Rhythm:** Asymmetric multi-column layouts, intentional negative space, structured data modules, and authoritative typography create an immediate impression of global technological dominance.
- **Dynamic Energy:** Laser-targeted crimson accents (`#C8102E`, `#E63946`) punctuate monochrome technical fields, directing user intent toward critical data paths and mission-critical actions.

## Colors

The system uses a technical high-contrast palette calibrated for extreme clarity and enterprise prestige. The default canvas mode is dark (`#0B0F14`), shifting to crisp clinical white (`#FFFFFF`) for documentation and high-density technical specifications.

### Primary & Energetic Accents
- **Primary Industrial Crimson (`#C8102E`):** Represents kinetic energy, industrial heritage, and core brand authority. Used for primary calls-to-action, structural highlights, and active telemetry states.
- **Vibrant Kinetic Red (`#E63946`):** An energetic high-visibility accent used for micro-interactions, alert flags, real-time indicators, and interactive hover feedback.
- **Laser Tint (`rgba(200, 16, 46, 0.15)`):** Semi-transparent red wash applied to technical grid overlays, radar-style graphs, and secondary state fills.

### Structural Neutrals & Surfaces
- **Pitch Void (`#0B0F14`):** Canvas background for cinematic dashboards, hero viewports, and showcase sections.
- **Technical Charcoal (`#121820`):** Base layer for surface cards, structural sidebars, and nested modules.
- **Elevated Steel (`#1B232E`):** Interactive surface layer for hovered cards, active rows, and dropdown menus.
- **Component Slate (`#252F3D`):** Highest dark elevation for floating toolbars, modal windows, and flyouts.
- **Metallic Platinum Border (`#333F50`):** Laser-cut dividing lines and structural bounding boxes.

### Light & Clinical Neutrals
- **Crisp Technical White (`#FFFFFF`):** High-readability surface layer for specification sheets, whitepapers, and contrast zones.
- **Warm Precision Gray (`#F4F6F8`):** Recessed canvas for light sections.
- **Machined Border Gray (`#E5E8EC`):** Division rules across light workspaces.

## Typography

The typographic hierarchy combines structural power with scientific accuracy:
- **Headlines (Outfit):** Modern geometric grotesque with muscular presence and tight letterforms. Set with subtle negative tracking to yield an engineered, architectural silhouette on wide formats.
- **Body & Editorial (Inter):** High-legibility neutral sans-serif designed for clean scanning across data-dense matrices, long-form project summaries, and analytical reports.
- **Technical & Telemetry (JetBrains Mono):** Reserved for technical readouts, operational timestamps, system IDs, parameter ranges, and uppercase categorical tags.

Typography rules require metadata and technical categorizations to be formatted in full uppercase via `label-caps`, preceded where possible by a systematic datum indicator (e.g., `SYS.REF // 094-EM`).

## Layout & Spacing

Layouts adhere to an asymmetric 12-column engineering grid engineered for precision data layouts, technical infographics, and modular executive storytelling.

### Grid & Breakpoints
- **Desktop (1440px+):** 12-column grid, `margin-lg` (4rem), `gutter-lg` (2.5rem). Allows asymmetric distribution (e.g., 4-column persistent metric rail alongside an 8-column cinematic project viewport).
- **Tablet / Small Desktop (768px - 1439px):** 8-column grid, `margin` (2rem), `gutter` (1.5rem). Secondary technical telemetry modules snap into stacked drawers or tabbed panes.
- **Mobile (< 768px):** 4-column fluid grid, `margin-sm` (1rem), `gutter-sm` (1rem). Multi-axis industrial tables become horizontally swipeable panes with fixed identification headers.

### Spacing Rhythm
Empty space functions as an active structural element rather than passive decoration. Component layouts use fixed 8px multi-multiples (`0.25rem` to `2.5rem`). Layout modules are bound by fine 1px structural dividing lines rather than loose floating gutters, evoking calibrated machine enclosures.

## Elevation & Depth

This design system avoids soft, decorative shadows in favor of architectural surface staging and tactile edge definition.

- **Low-Contrast Technical Outlines:** Elevation is primarily achieved through single-pixel borders using `#333F50` against dark surfaces and `#E5E8EC` against light surfaces.
- **Tonal Layering:** Visual hierarchy rises from Canvas Ground (`#0B0F14`) to Modular Container (`#121820`), hovered interaction (`#1B232E`), and modal overlay (`#252F3D`).
- **Precision Ambient Shadows:** Floating layers (e.g., industrial flyouts, live toolbars) utilize sharp, technical shadows without diffuse spread: `0 8px 24px -4px rgba(0, 0, 0, 0.65), 0 0 0 1px #333F50`.
- **CAD Grid & Datum Underlays:** Technical viewports incorporate a subtle background blueprint grid (`linear-gradient(rgba(51, 63, 80, 0.15) 1px, transparent 1px)`) spaced at 24px intervals, grounding elements in an explicit coordinate matrix.

## Shapes

The design system enforces zero-radius sharp geometry (`roundedness: 0`). 

Every visual module, card, button, modal window, and input field features absolute 90-degree squared corners (`0px`). This uncompromising architectural stance differentiates the interface from consumer software and reinforces the precision of CNC machining, laser fabrication, and heavy industrial hardware. 

Where decorative corner detailing is required for status badges or framing brackets, cut-corner chamfers (45-degree 4px-8px clips via `clip-path`) or fine corner registration tick marks (`+`) are applied to communicate surgical fabrication standards.

## Components

### Buttons & Interactive Controls
- **Primary Kinetic Button:** Hard-edged rectangular shape, `#C8102E` background, pure white bold uppercase text (`label-caps`), 1px solid `#E63946`. On hover: `#E63946` background with a 1px inner border flash and a `+` datum symbol shifting 4px right.
- **Technical Secondary Button:** `#121820` background, 1px solid `#333F50`, `#FFFFFF` typography. On hover: border transitions to `#C8102E` with text shifting to crisp metallic platinum.
- **Ghost Action:** Transparent background, 1px dashed `#333F50`, monochrome icon-leading, hover solidifies to `#1B232E`.

### Form Fields & Inputs
- **Base Style:** 0px radius, `#0B0F14` interior, 1px solid `#333F50`, `tech-data` typography in `#FFFFFF`.
- **Active / Focus:** Border changes to 1px solid `#C8102E` with an optional 1px vertical focus indicator along the left edge.
- **Data Labels:** Floating uppercase `label-caps` pinned above the input frame, accompanied by an alphanumeric reference index (e.g., `FLD_01 // PRESSURE_THRESHOLD`).

### Badges, Status Chips & Tickers
- **Telemetry Chips:** Flat 0px rects featuring a 6px pulsing square indicator (green for nominal, amber for testing, `#C8102E` for critical overload). Framed with a 1px border at 20% opacity of the indicator color.
- **Live Data Tickers:** Edge-to-edge modular strips running at the bottom or top of viewports, displaying stock performance, turbine RPMs, global plant output, and operational runtimes using monospaced values in real time.

### Cards & Industrial Modules
- **Modular Data Cards:** Set in `#121820` with a 1px `#333F50` outline. The upper-right corner features an etched coordinate reference (e.g., `SEC-404-B`).
- **Interactive State:** Hovering elevates the background to `#1B232E`, draws a 2px top accent line in `#C8102E`, and illuminates corner datum crosshairs.

### Checkboxes & Segmented Controls
- **Checkboxes:** Sharp 16px squares with 1px `#333F50` border. Active state fills with `#C8102E` and features a stark white scalar checkmark.
- **Segmented Unit Selectors:** Direct adjacent block cells enclosed in a single perimeter border. Selected cell turns `#C8102E` with inverted high-contrast white text.

### Mega-Menus & Showcase Navigation
- Multi-column technical navigation panels revealing engineering schematics, product cutaways, global plant telemetry, and enterprise business units organized with tabular lines, indexing columns, and live system latency readouts.
